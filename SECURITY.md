# Security policy

Do not submit API keys, database dumps, access tokens, server addresses, private prompts, production logs, or user media in an issue.

If you discover an exposed secret or private implementation, contact the repository owner privately. Include only the affected path and a minimal description. Do not include the secret value in the report.

Before deployment, copy `.env.example` to `.env`, replace placeholders locally, and keep `.env` outside version control.
